{# Quick Links — display only, and draggable. NO DEFAULTS. The four system tiles (Azure DevOps, Artifactory, SonarQube, ServiceNow) used to be hard-coded here and rendered before anything an admin had added, so the admin's own links were always shoved to the back of a list they did not choose. The list is now exactly what an admin put in it, in Platform Managing → Quick Links, and nothing else. An empty portal shows an empty widget, which is honest. IT WRAPS, IT DOES NOT SCROLL SIDEWAYS. This used to be one non-wrapping row in an `overflow-x-auto` strip. Two things were wrong with that: a vertical mouse wheel does not scroll a horizontal container (only Shift+wheel does), so the list read as frozen; and everything past the eighth link was simply off-screen. Now the tiles wrap onto as many rows as they need, clamped to two rows with a "Show all" toggle so a long list cannot push the whole dashboard down. TILES ARE A FIXED WIDTH. The gaps used to be set by the longest name in the row, so the spacing visibly changed from row to row. Every tile is now the same width and the label wraps inside it, which makes the grid regular no matter what anything is called. ORDER IS THE USER'S. Drag any circle to move it. The order is saved per-browser, so rearranging your own dashboard cannot disturb anybody else's — the links themselves are one shared list an admin controls, but where they sit is nobody's business but yours. A link an admin adds later appears at the end for everyone; a link removed simply drops out of your order. TWO LISTS, ONE STRIP. The SHARED links are an admin's, managed in Platform Managing; this widget only displays them. Your OWN links are added, edited and removed right here from the "+" tile at the end, because the moment you want a tile is the moment you are looking at the place it is missing from. Only you ever see yours — they are a separate table, not a flag on the shared one, so no query can confuse the two. #}
