{# DevBot AI -- the chat page. Laid out like the chat assistants people already know: past conversations on the left, one centred column of questions and answers, the box to type in at the bottom, and the model picker in the page header. Everything is loaded by the script below from /api/devbot; the server only renders this shell. WHAT THE PERSON ALWAYS SEES * which model is answering, and whether it can read live data; * their key's limits (requests and tokens a minute), and what each answer cost; * which systems each answer read, and a link to every source; * that DevBot works with THEIR tokens and never changes anything unconfirmed. The answer arrives as server-sent events over a POST (fetch + a stream reader), so it is drawn as it is written. The page never builds HTML from model output without escaping it first: the Markdown renderer below escapes, then formats, and only lets links to http(s) addresses through. Written without template literals on purpose: the markup is assembled with string concatenation, so there is no backtick anywhere in this script for a stray one in a comment to unbalance (scripts/check_inline_js.py). #}
