{# "Ask DevBot" on hover. Rest the pointer on a row of a widget for a moment and the row lights up with an Ask DevBot chip on its top edge; clicking the chip opens DevBot with a question about that row, which it asks at once (window.portalDevbot.ask). From the keyboard: Tab onto anything in a row and the chip appears the same way; Alt+A asks it (matched on the physical key, so it works in a Hebrew layout too). A row takes part by carrying the question: data-devbot-ask, written by the widget through window.portalDevbot.attr(question), which escapes it and writes nothing when DevBot is not set up. The engine below knows no widget: a new widget joins by adding that one attribute to its rows. The chip is a quick way in, never the only one: the rows that matter most (a failed run, a work item) keep their own Explain and Ask DevBot buttons, which work on touch. Settings can switch the chip off (portal-devbot-hover). Included from banner.html only where DevBot is set up. #}
