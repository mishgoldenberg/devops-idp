{# DevBot's page search index. Included by platform-managing-container.html. An admin names the Confluence spaces DevBot should search by meaning, and gives the two credentials the Hub builds the index with: a read-only Confluence token and an AI key for the Hub itself. Saving checks both before keeping them (every space readable, the model able to embed a sentence), so a setting that would fail in a build nobody watches fails here instead, with the reason. Fed by /api/devbot/index, which re-checks admin access itself; this card sitting on an admin page is a convenience, never the permission. Credentials go in and never come back: the page is only told whether each one is set. #}

DevBot search index

Lets DevBot find Confluence pages, and fixes written down before, by what they mean, not only by their words: an English error finds the Hebrew page, or the closed bug, that fixes it. The Hub keeps an index of what you choose below and catches up with edits on its own.

Past fixes from Azure DevOps

Work items of these types that have a fix written in them, read with the Hub's admin token. They are found by their title and description, and shown to anyone who asks as the reviewed problem and fix; the link to the work item is added only for someone whose own Azure DevOps token can open it.

Past fixes from ServiceNow tickets
Tickets are found by their short description and description. Each resolution note is reviewed before it is kept: rewritten clearly and professionally, and held back when there is no usable fix in it. Everyone who asks DevBot can be shown the reviewed problem and fix of any ticket -- never the original note, who raised or fixed it, or a link, since people here have no ServiceNow account to open it with.
Review the past fixes

What DevBot shows people, exactly as the review rewrote it. The original notes are not kept; Open shows the work item. Hide keeps a fix from everyone, through every rebuild, until you show it again. Review again takes it out of answers until the next build has reviewed it anew.
