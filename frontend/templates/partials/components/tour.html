{# Guided tour — the first-run walkthrough. Dims the page, cuts a hole around one element at a time, and explains it in a small popover with Back / Next / Skip. Runs itself once, the first time someone opens the dashboard, and can be replayed from the Help menu or the "?" shortcut afterwards. WHY IT IS BUILT THIS WAY * The dim is ONE element with a very large spread box-shadow, not four panels and not an SVG mask. `box-shadow: 0 0 0 9999px rgba(0,0,0,.55)` paints everything outside the highlight and nothing inside it, in a single layer that cannot develop seams when the page scrolls or the target is near an edge. * Every step is optional. A selector that matches nothing is skipped rather than showing an empty spotlight — the sidebar and dashboard differ between admins and regular users, and a tour that breaks for half the org is worse than no tour. * Nothing here is a Tailwind class that would need compiling: output.css ships precompiled, so all of this is hand-written CSS in this file. #}
