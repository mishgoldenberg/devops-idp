{# Command palette (Ctrl / ⌘ + K). Ctrl+K used to focus the header search box. That is a search shortcut, not a palette: it can only find *content*, so "go to Approvals", "switch the theme" or "replay the tour" were still things you had to know where to click. This is the pattern from every tool these users already live in — one keystroke, type a few letters, hit Enter. Commands are matched instantly from a local list; content results come from /api/search and stream in underneath, so the palette is useful on the first keystroke and better on the third. #}
