{# What's New. An editorial page, not a widget: a sticky rail on the left carrying the version and its dates, and the writing on the right. That shape is chosen because of how this page is actually read — people scroll looking for the release they are on, and a version number that scrolls away with its own entry is the one thing they are scanning for. Everything here is rendered server-side from backend/app/changelog.py, which is baked into the image. There is no fetch, so there is no empty state, no spinner and no way for the page to arrive blank because an integration was slow. The only script is the filter, and it hides with `display` rather than the `hidden` attribute — any class that sets `display` beats the attribute, and this page has several. #}
