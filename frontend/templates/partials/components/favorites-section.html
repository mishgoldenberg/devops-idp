{# Favorites strip that sits above the widget grid on the dashboard. Self-fetches from /api/favorites; hidden on first render until the user actually has favorites (so there's no empty shell cluttering the dashboard on fresh accounts). A global `window.portalFavorites` helper is exposed so every other page that wants to toggle a favorite (Support row, global-search result) can call a single entry point without duplicating the fetch wiring. Kept on window so it can be used from inline onclicks if we ever need it, and so an external HTMX refresh can request a reload of the section. #}
